## Token-Efficient Workflow

- Keep prompts and responses concise.
- State each instruction only once.
- Do not repeat project context already available in the repository.
- Read only files relevant to the current task.
- Avoid scanning the entire repository unless necessary.
- Do not print complete files when a small diff is enough.
- Summarize completed work briefly.
- Report only:
  - files changed
  - important decisions
  - test/build result
  - unresolved errors
- Do not explain obvious code unless asked.
- Do not provide long plans before simple tasks.
- Work on one requested feature at a time.
- Reuse existing components and utilities.
- Do not add examples unless needed.
- Stop after completing the requested task.
